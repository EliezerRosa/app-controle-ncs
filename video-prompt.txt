Tópicos obrigatórios (ajuste a ordem para manter ritmo fluido):

1. Introdução
   - Contextualize o “App Controle NCs” como uma SPA React + Vite que auxilia congregações a gerenciar territórios de pregação.

2. Problema
   - Explique a necessidade de consolidar dados de territórios e histórico de visitas, evitando planilhas dispersas e intervenções manuais no GitHub.

3. Solução
   - Descreva o app como cliente React que usa a GitHub REST API para persistir o arquivo `data/db.yml`.
   - Destaque o uso de Personal Access Token (PAT) distribuído de forma ofuscada em `public/token.json`.

4. Arquitetura e destaques técnicos

5. Segurança do PAT

   - Cite a revogação/rotação via script `scripts/publish-token.mjs`.

6. Fluxo operacional
   - Demonstre o caminho do usuário: login por e-mail, seleção de território/quadra, alteração de status das residências, sequenciamento de casas, administração de usuários.
